Linear Regression in Machine Learning

Linear regression is a fundamental statistical and machine-learning technique used to understand relationships between variables and predict numerical outcomes. It helps transform observed data into interpretable mathematical models.

TOPIC: MACHINE LEARNING   ·   METHOD: SUPERVISED LEARNING   ·   TASK: NUMERICAL PREDICTION
01 / DESCRIPTION

What is Linear Regression?

Linear regression is a supervised learning algorithm that learns a relationship between one or more input variables and a numerical target variable. It estimates a line or linear equation that best represents the observed relationship in the training data.

For example, a model can study the relationship between the number of hours a student studies and their examination marks. After learning from existing observations, it can estimate marks for another number of study hours.

Independent variable (X)

The input used to estimate an outcome. Example: study hours.

Dependent variable (Y)

The numerical outcome being predicted. Example: exam marks.

Main objective: Find a suitable linear equation that minimises the sum of squared differences between actual and predicted values on the training data.

Types of Linear Regression

TypeDescriptionExample
Simple Linear RegressionUses one input variable.Study hours and marks.
Multiple Linear RegressionUses two or more input variables.House price from area, age and location features.
02 / MATHEMATICAL FORMULA

Mathematical Foundation

3.1 Regression equation

ŷ = b₀ + b₁x
SymbolMeaning
ŷPredicted value of the dependent variable.
xIndependent variable.
b₀Intercept of the fitted line.
b₁Slope of the fitted line.

3.2 Calculation of the slope

b₁ = Σ[(xᵢ − x̄)(yᵢ − ȳ)] / Σ[(xᵢ − x̄)²]

The slope describes the predicted change in Y for a one-unit increase in X. Its interpretation depends on the units of the variables.

3.3 Calculation of the intercept

b₀ = ȳ − b₁x̄

The intercept is the fitted value of Y when X equals zero. Depending on the data, zero may not be a meaningful input value.

3.4 Least Squares Method

SSE = Σ(yᵢ − ŷᵢ)²

Ordinary least squares finds the coefficients that minimise the sum of squared residuals. A residual is the difference between an observed value and its fitted prediction.

3.5 Statistical measures

Mean

x̄ = Σxᵢ / n

The arithmetic average of the observations.

Variance

s² = Σ(xᵢ − x̄)² / (n − 1)

The sample variance measures the spread of observations.

Coefficient of determination

R² = 1 − SSE / SST

Measures how much variation is explained by the fitted model under the usual intercept-model definition.

Root Mean Squared Error

RMSE = √[Σ(yᵢ − ŷᵢ)² / n]

Measures typical prediction error while giving larger errors more weight.

03 / PYTHON IMPLEMENTATION

Implementing Linear Regression with Python

This practical example uses study hours to estimate examination marks. The dataset is included in the code, so a separate CSV file is not required.

Libraries required

pip install numpy pandas matplotlib scikit-learn

Complete Python program

linear_regression.py 
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
from sklearn.metrics import (
    mean_absolute_error,
    mean_squared_error,
    r2_score
)

# 1. Create the sample dataset
data = {
    "Study_Hours": [1, 2, 3, 4, 5],
    "Exam_Marks": [35, 40, 50, 55, 65]
}

df = pd.DataFrame(data)

# 2. Separate input and target variables
X = df[["Study_Hours"]]
y = df["Exam_Marks"]

# 3. Create and train the model
model = LinearRegression()
model.fit(X, y)

# 4. Predict values for the dataset
y_pred = model.predict(X)

# 5. Display the regression equation
print("Dataset:")
print(df)

print("\nSlope:", model.coef_[0])
print("Intercept:", model.intercept_)
print(
    f"Regression equation: Marks = "
    f"{model.intercept_:.2f} + "
    f"{model.coef_[0]:.2f} * Hours"
)

# 6. Calculate descriptive statistics
print("\nDescriptive Statistics:")
print(df.describe())

# 7. Evaluate the fitted model
print("\nModel Evaluation:")
print("MAE:", mean_absolute_error(y, y_pred))
print("MSE:", mean_squared_error(y, y_pred))
print("RMSE:", np.sqrt(mean_squared_error(y, y_pred)))
print("R-squared:", r2_score(y, y_pred))

# 8. Predict marks for 6 study hours
new_data = pd.DataFrame({"Study_Hours": [6]})
prediction = model.predict(new_data)[0]
print("\nPredicted marks for 6 hours:", prediction)

# 9. Plot actual observations and regression line
plt.figure(figsize=(8, 5))
plt.scatter(
    X["Study_Hours"], y,
    color="teal", s=75, label="Actual marks"
)
plt.plot(
    X["Study_Hours"], y_pred,
    color="darkorange", linewidth=2.5,
    label="Regression line"
)
plt.xlabel("Study Hours")
plt.ylabel("Exam Marks")
plt.title("Linear Regression: Study Hours vs Exam Marks")
plt.legend()
plt.grid(alpha=0.25)
plt.tight_layout()
plt.show()

# 10. Plot actual versus predicted values
plt.figure(figsize=(7, 5))
plt.scatter(y, y_pred, color="teal", s=75)
lower = min(y.min(), y_pred.min())
upper = max(y.max(), y_pred.max())
plt.plot(
    [lower, upper], [lower, upper],
    linestyle="--", color="darkorange",
    label="Perfect prediction"
)
plt.xlabel("Actual Marks")
plt.ylabel("Predicted Marks")
plt.title("Actual vs Predicted Values")
plt.legend()
plt.grid(alpha=0.25)
plt.tight_layout()
plt.show()

Explanation of the program

  1. Import libraries: NumPy handles numerical calculations, Pandas manages tabular data, Matplotlib creates graphs, and Scikit-learn trains the model.
  2. Create the dataset: Study hours are the input and examination marks are the target.
  3. Train the model: LinearRegression() creates the model, while fit() estimates the coefficients.
  4. Generate predictions: predict() calculates fitted values from the input data.
  5. Evaluate performance: MAE, MSE, RMSE and R² summarise the errors and fitted model.
  6. Visualise the results: The first graph shows the fitted line; the second compares actual and predicted values.
Important: This small dataset is intended for demonstration. The reported metrics are calculated on the same data used to fit the model, so they do not measure performance on unseen observations. For real projects, use a suitable train/test split or cross-validation.

Example of a business use case

A company wants to estimate monthly sales based on advertising expenditure. It collects historical records, examines the relationship between spending and sales, trains a regression model and evaluates prediction errors on held-out data.

If the relationship is reasonably linear and the evaluation is satisfactory, the model can help with planning. The result remains an estimate, and other factors may influence actual sales.

06 / CONCLUSION

Conclusion

Linear regression is a foundational technique in machine learning that uses a linear equation to estimate numerical outcomes from input variables. Its mathematical foundation includes the slope, intercept and least-squares method.

Python libraries such as NumPy, Pandas, Matplotlib and Scikit-learn make it possible to prepare data, train a model, calculate statistical metrics and visualise results efficiently.

Linear regression is useful in business, education, finance, real estate and environmental analysis. Reliable applications require suitable data, checking assumptions, evaluating predictions on unseen observations and interpreting results carefully.
